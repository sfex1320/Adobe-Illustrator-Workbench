# 0.6.39：画板导出范围、合集、样式吸取与更新

本记录区分已执行验证、待安装后检查和既有未解决问题，不把浏览器模拟视为真实 CEP 验收。

## 改动

- AI 画板导出在受保护工作副本中剔除选定范围外的对象，递归处理跨画板群组、隐藏与锁定层，再裁切跨边界内容。修复原先仅设置画板范围却保留整个文档设计的问题。
- AI/SVG/EPS/PDF 合集：多画板或多对象写入一个文件，保留相对位置及叠放顺序。AI 画板合集保留所选画板；其他合集格式为联合页面，画板之间空隙透明/空白。
- 样式吸取为独立主模块：来源取样、按属性勾选、逐项对象定位、向当前目标赋予；递归展示群组与剪贴蒙版。图形支持纯色填充/描边及宽高；文字支持统一字体/字号/颜色/垂直缩放等及区域框尺寸。混合属性明确提示，局部字符操作不改写其他文字。
- 画板四边增减可独立或锁定统一调整；文档四边出血可读写，原生接口通过正式 SDK 槽位校验。出血每边 0–72 pt，作用于文档。
- 画板命名下拉框与范围按钮、设置存储格式与操作按钮之间增加间距，窄面板允许按钮换行。
- 设置新增更新检查、GitHub 直连与 HTTPS 镜像前缀；RSA 签名、大小/SHA-256、解压路径校验，再调用退出等待安装队列。
- 新增单 EXE 安装器，自动识别系统注册的 Illustrator 30 目录，同时部署 CEP 和原生模块；无法写入时如实失败并回滚，不强制关闭软件。
- 独立渲染依赖为可选本机组件。缺失时核心工具仍可安装，相关渲染明确提示不可用。RGB 源稿→CMYK TIFF 原生路径因本轮崩溃被隔离，界面路由到独立渲染；宿主入口也拒绝原生调用。

## 支持边界与后续优化

1. **兼容**：Windows x64 / Illustrator 2026 30.0.0 实测。其他30.x未逐一验证，2025及更早、macOS未支持。
2. **画板导出**：串接文字为保护排版，可能仍保留蒙版隐藏的编辑内容；普通对象和群组子对象已剔除。需要彻底剥离串接文字的独立拆分，不能承诺文件内绝无隐藏数据。
3. **样式**：渐变、图案、多重外观、效果与复杂混排的完整克隆未实现；图像自身没有路径填充/描边时需操作框/蒙版。上限300个对象、5000字符；不可用属性不伪装成成功。
4. **宿主稳定性**：2026-09-23 16:03 RGB→CMYK TIFF 测试发生0xc0000374堆损坏，已隔离该路径；16:22 AI重开时发生0xc0000005访问冲突，冷启动后相同及扩展样例通过，根因仍未证实解决。不能宣称历史崩溃已根治。没有终止或保存用户稿件。
5. **安装更新**：EXE没有Windows Authenticode签名；更新清单有项目RSA签名。写目录权限仍由系统决定。镜像需要用户配置且支持GitHub重定向，实际网络可用性需分别检查。签名私钥不进入仓库或包。
6. **CEP**：0.6.39冷启动和完整更新按钮/进程联调待正常重启后确认；本轮浏览器检查、宿主命令与安装哈希不能代替它。已有输入法个别输入框问题未重新复现，不宣称修复。
7. **其他缺口**：可靠的文字自动适配、原生关键对象完整顺序、画板图层绑定、实时对称仍未全部实现；复杂导出仍需要受保护工作副本。优先稳定性，其次串接文字与复杂样式，再扩展宿主版本和更新回滚/诊断界面。
8. **依赖维护**：`npm audit --json` 报告 exceljs/间接 uuid 共2项中等告警，没有 high/critical。自动修复建议涉及主版本变动，本轮未盲目降级；保留为表格导入模块后续兼容回归事项，不宣称已修复。

安装与远程发布的最终状态另见本记录末尾的交付收据；尚未取得的状态不写成完成。
